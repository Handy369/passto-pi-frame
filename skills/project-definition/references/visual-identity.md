# Visual Identity

> **last_verified: 2026-05-14**
> migrated from: `agent-design/references/visual-identity.md`

## 作用

当用户需要先定义 **品牌视觉身份**，如 Logo 方向、CIP 套件、品牌使用规则时，进入本模块。

本模块关注的是品牌设计定义与交付清单，不是单纯执行生成命令。

---

## 适用场景

- “帮我设计一个 Logo 方向”
- “我要一套企业形象 / CIP”
- “先定义品牌风格、行业气质、主色和物料”
- “给我一套品牌视觉 brief / 指南”

---

## 核心输出

1. **品牌视觉 brief**
2. **Logo 风格方向**
3. **主色 / 辅色 / 字体建议**
4. **CIP 交付物清单**
5. **品牌使用规则**
6. **生成与评审工作流建议**

---

## 设计判断维度

### Logo 方向
- 简约 / 几何 / 专业 / 活力 / 复古 / 科技未来感
- 根据行业与品牌气质选 1-2 条主路线，不要混太多风格

### 配色心理
- 蓝：专业、信任、科技
- 绿：自然、增长、健康
- 红：激情、能量、即时性
- 紫：创意、奢华、未来感
- 黑灰：高端、克制、专业

### CIP 交付
至少区分：
- 纸质物料
- 数字物料
- 品牌指南
- 应用示例

---

## 使用规则最少要明确

- 安全区域
- 最小尺寸
- 禁止拉伸 / 改色 / 加特效
- 可用背景 / 禁用背景
- 主色 / 辅色 / 强调色占比
- 标题与正文字体角色
