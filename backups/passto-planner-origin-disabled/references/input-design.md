# Input Design

目标：把分析阶段识别出的所有输入，映射到当前方案的输入承载方式中。

## 必须覆盖
- 输入入口
- 结构化参数
- 必要时的选择 / 输入 / 确认交互
- env/config/dependency 映射

## 设计要求

### 1. 用户输入必须逐项映射
输出表格：

| 输入项 | 原系统输入方式 | 方案中的承载方式 | 使用能力 | 风险 |
|--------|----------------|------------------|----------|------|

### 2. 环境变量 / 配置必须逐项映射
输出表格：

| 名称 | 原系统来源 | 方案中的承载方式 | 是否保留 env | 备注 |
|------|------------|------------------|---------------|------|

### 3. 不可简化输入节点要单独标记
例如：
- 多选不能变单选
- 结构化问题不能退化成纯文本输入
- review gate 不能退化成 yes/no
