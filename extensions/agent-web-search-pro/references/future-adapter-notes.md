# Future Adapter Notes

当前 `runSearchAdapter()` 是一个骨架函数，用于保证：
- API 结构先稳定下来
- 在没有真实联网实现时也能安全返回
- 不伪造来源
- 审查时可以明确区分“降级结果”和“真实异常”

## 后续建议接入点
可以将 `runSearchAdapter()` 替换为以下能力之一或组合：
- 搜索 API（如 Tavily、SerpAPI、自建 search backend）
- 网页抓取 / 正文提取服务
- 站点特定 extractor（GitHub、YouTube、Twitter、V2EX）
- 多阶段检索：先搜索，再抓取前 N 个候选页面摘要

## 接入要求
真实 adapter 接入后应继续满足：
1. 默认返回精简摘要
2. 结果必须带来源
3. 无法确认来源时，不输出强结论
4. 出错时优先返回明确错误或降级结果
5. 兼容命令态与工具态双入口
6. 保持输出截断保护
7. 仅“无 adapter / 暂不可用”这类情况可走降级语义；真实运行异常应抛错

## 推荐演进方向
- 为不同站点实现独立 parser
- 增加去重与排序策略
- 增加时间范围与语言过滤
- 增加“先搜索后深读”的预算控制
- 增加引用格式标准化（标题、URL、抓取时间、来源类型）
